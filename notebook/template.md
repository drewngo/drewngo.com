## How to add an entry

1. Copy this file and rename it, e.g. `fir-filter-notes.md`. The file name becomes the link: `#/notebook/fir-filter-notes`.
2. Line 1 is the title. Line 2 is the date as `YYYY-MM-DD`. Leave line 3 blank.
3. Write the entry below that in Markdown.
4. Push. It shows up in the notebook list, newest first.

To keep a draft hidden, start the file name with `_`, e.g. `_draft-idea.md`.

## What formatting works

Paragraphs are separated by a blank line. **Bold** (shows as small caps), *italics*, `inline code` and [links](https://example.com).
