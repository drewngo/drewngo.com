FireWatch

2nd place · Lockheed Martin Skunk Works hackathon
github
  • satellites
  • goes / viirs / modis
  • lora mesh
  • meshtastic
  • python
  • react

A detect, confirm and respond system for rural Kansas volunteer fire districts, built in one weekend by a five-person team at Firewatch 2026, the WSU Innovation Works × Lockheed Martin Skunk Works hackathon. It fuses GOES, VIIRS and MODIS satellite hotspots with power-line faults and texted reports, then pages over SMS and a Meshtastic LoRa mesh, so alerts still go out on one bar of cell.

Built the fire spread forecast: an NLCD/CDL fuel map, terrain, hourly wind and a 24-member ensemble. Back-tested against archived VIIRS, MODIS and GOES-19 fire detections from real Plains fires (Anderson Creek, Starbuck, Ranger Road): starting from the first satellite pass, its range covered 77% of later polar-orbiter detections, against 34% for a single-run baseline. Also wrote the expected-loss playbook that recommends whether to page the district, a fire-day danger model fitted to 538 Kansas wildfires, and a simulated FireNode sensor network with free, paid and offline views.

NOAA APT Satellite Decoder

github
  • verilog
  • nexys a7-100t
  • vivado
  • python
  • dsp
  • fixed-point fir

A dual-implementation NOAA APT weather-satellite decoder for a Xilinx Artix-7 FPGA, turning archived pre-demodulation IQ recordings into decoded imagery. A 5-stage Python reference pipeline validates the full chain: a Kaiser-windowed channel-select FIR, FM demodulation by phase differentiation, and a cascaded two-stage decimation bank that brings 62,400 Hz to the 4,160 Hz APT word rate exactly at Nyquist, matching NOAA's original zero-margin design.

Now in RTL: a CORDIC-based fixed-point FM demodulator and a time-multiplexed serial FIR that reuses a single DSP slice across every tap, inside a ~1,600-cycle-per-sample budget at 100 MHz.

FPGA Real-Time Temperature Monitor

github
  • verilog
  • i2c
  • vivado
  • icarus verilog

A from-scratch I2C master FSM reading an ADT7420 on a Nexys A7-100T, with the clock divided into quarter-phases so SDA transitions land well away from SCL edges. Readings become Celsius or Fahrenheit BCD on a multiplexed seven-segment display. A self-checking testbench models the ADT7420 as a slave and asserts every byte and ACK/NACK bit across randomized read cycles.
